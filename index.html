        怎麼玩？

        一步步走完 RCA 清洗 → 薄膜沉積 → 微影 → 顯影 → 蝕刻 五道半導體製程， 親手做出一片有你圖案的晶圓，最後拿結業證書。

        1. 用手勢：張開手掌面對鏡頭 → 出現藍綠色骨架 → 捏合拇指與食指拿起器材（藥瓶、晶圓、光罩），移動、張開手放下。
        2. 用滑鼠 / 觸控：沒有鏡頭也能玩 —— 左側互動面板的按鈕直接點， 畫面上的器材直接按住拖曳。
        3. 每一關左上角有子步驟列，跟著提示做；卡住時看右側「操作說明」。
        4. 畫面很卡？設定 → 效能模式選「效能優先」。

        找不到手？確認光線充足、手完整入鏡；鏡頭方向相反就切換上方「鏡像」。
